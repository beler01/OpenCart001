# OpenCart Selenium Automation Framework

## Overview
End-to-end hybrid automation framework for testing 
OpenCart e-commerce application.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Extent Reports

## Framework Features
- Page Object Model design pattern
- Cross browser execution
- Data driven testing
- Extent HTML reports with screenshots
- TestNG parallel execution

## Test Coverage
- User Registration & Login
- Product Search
- Add to Cart
- Checkout Flow
- Order Validation

## How To Run
1. Clone the repository
2. Import as Maven project in Eclipse/IntelliJ
3. Run testng.xml
4. Reports generated in /reports folder
